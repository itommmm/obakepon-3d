# プレイテスト報告(おばけポン・チャプター1「よふけの ポンポン小学校」)

## 方法

- **ボット**: `game/scripts/playtest.mjs`。実際のキー入力と同じ入力経路で操作する(キーはページ内で `window` に発行、視点はマウス移動と同じ経路のテスト用フック `look`)。
- **作戦**
  - 慎重派 (`careful`): 懐中電灯を消して歩く。ドラゴンチーノの周りを避ける。追われたら非常灯へ逃げて待つ。
  - 無謀派 (`reckless`): 懐中電灯を点けたまま走る。追われたら非常灯へ逃げる。
- **時間**: ゲーム内の時間で数える(描画が遅いため、実時間の約6〜8割で進む)。
- **限界**: ボットは位置や敵の状態を読んで動く。怖さや面白さは測れない。測ったのは「仕組みが意図どおり働くか」「どこで詰まるか」「どれくらい時間がかかるか」。

## 主な発見

### 1. 電源を入れた後の脱出が成立しない(最重要)

- 電源を入れてから最初に捕まるまで、どの試行も **約8〜10秒**(ゲーム内)。
- 捕まる場所は、広間の東の出口付近(セル (15〜16, 11〜12))。怒った敵は、音楽室との境目の通路 (16,11)/(17,11) に立っていた。
- 原因(コードと数字で確認):
  - **脱出ルートが音楽室を通る**。敵は音楽室から出てくる。電源直後の怯みは3.5秒(`Game.ts` 478行)で、その後すぐ出口へ向かう。
  - **怒った敵は、安全地帯の外にいれば距離に関係なく気づく**(`Monster.ts` 275行。距離の上限がない)。逃げるには、敵より速く動き続けるしかない。
  - **スタミナの計算**: 走り続けると、走る→息切れ→歩く(回復)を繰り返す。平均は約 3.6 m/秒(走 5.6、歩 3.3、息切れ時 2.5)。理想的にスタミナを管理しても約 4.15 m/秒。敵は 4.3 m/秒。ほぼ同じか、敵のほうが速い。
- 結論: 今の作りでは、敵が出口の通路で待ち伏せする形になり、ボットは一度も抜けられなかった。人が安全地帯などを使えば抜けられるかは **未検証**。

### 2. 最初のヒューズ集めは、慎重派と無謀派で大きく違う

- 慎重派は3本を142秒で分電盤へ。捕まったのは1回だけ。
- 無謀派は、懐中電灯を点けっぱなしにしたため電池が72秒で切れた。その後は暗闇で見つかりやすくなり、616秒かかった。走りすぎてスタミナ切れも14回あった。
- 懐中電灯と走りの使い分けは、結果にはっきり効いている。これが意図どおりかは判断が必要。

### 3. 仲間の2体は、プレイテストでは一度も反応しなかった

- 試験の経路が、1階廊下とドラゴンチーノの周りを通らなかった(慎重派は意図的に避けた)。
- 以前の自動テストでは確認済み: ワニーニの警報(画面に「ワニーニに見つかった」と出る)、ドラゴンチーノの目覚め(走って近づいたとき)。
- **プレイテストでの確認は未了**。

### 4. 仕様と実装のずれ(コードを読んで確認。プレイテストでは未測定)

- **ドラゴンチーノ**: 説明は「そっと歩けば起きない」。しかし実装では、1.7m 以内に近づけば歩いていても起きる(`Dragontino.ts` 219行)。理科準備室の入口は通路が3mしかないため、通ると必ず起きる。
- **怒った敵の気づき**: 距離の上限がない(前述、`Monster.ts` 275行)。意図どおりかを決める必要がある。

## 提案(どれを採るかは判断が必要)

- **A. 電源後の敵の位置**: 脱出ルートから離れた場所(図書室など)で怯ませる。音楽室を通らずに出口へ行ける。
- **B. 怒りの気づきに距離の上限**: 例えば 25〜30m。遠くから追われなくなる。
- **C. 脱出ルートに安全地帯を追加**、または音楽室の位置を変える。
- **D. 怯みの時間を延ばす**: 3.5秒 → 6秒程度。
- **E. ドラゴンチーノの起床条件**: 仕様どおりなら「走るときだけ起きる」に寄せる(または近距離の判定を走るときだけにする)。

調整したら、同じ「最後の脱出の試験(fuse3)」で脱出率を比べられる。
