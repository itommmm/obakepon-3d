# おばけポン 3D — 企画書 v0.4(ブレインロット小学校版)

> 方向性: 「Poppy Playtime のような」一人称ホラー × **ブレインロット風キャラクター** × **夜の小学校**。
> 「物 + 動物」を無理やり合体させた、意味不明なのに耳に残る名前のキャラ、という作風だけを参考にする。キャラクター・名称・デザインはすべてオリジナル(既存のミームキャラは使わない)。

## 世界観
**ポンポン小学校**では、ある時期から子どもたちの間で「ブレインロットごっこ」が流行った。持ち物と動物を合体させた変な生き物を描いては、変な名前を叫ぶ遊びだ。
いちばん人気は、6年2組の誰かが描いた **ランドセルザメ・ガブガブーノ**。
ある夜、学校に忘れ物を取りに来たプレイヤーは、停電した校舎に閉じ込められる。暗い廊下の奥から聞こえてくるのは、上履きの足音と「ガブ…ガブ…ガブーノ…」という声。

### キャラクター
| 名前 | 役割 | デザイン |
|---|---|---|
| **ランドセルザメ・ガブガブーノ** | 追いかけてくる主役 | 身長約4mの真っ赤なランドセル。かぶせ(フタ)がサメのアゴになっていて、開くとギザギザの歯が並ぶ。背中に背びれ、両脇に胸びれ。白い靴下と上履きを履いた、異様に細長い人間の足で歩く。名札は「6ねん2くみ」 |
| チョーク・ワニーニ | 1階廊下の見張り(**光**に反応) | 白いチョークの体を持つワニ。ライトを点けたまま視界に入ると鳴いて、ガブガブーノを呼ぶ |
| ぎゅうにゅうパック・ペンギーノ | 図書室に立つ不気味な仲間 | 牛乳パックの体を持つペンギン(約2m)。プレイヤーが目をそらしている間だけ、こちらへ向き直る |
| うわばき・ドラゴンチーノ | 理科準備室の入口で眠る番人(**音**に反応) | 上履きの体を持つ竜。いびきで存在を予告し、近くで走ると起きて吠え、ガブガブーノを呼ぶ |

## 1. デザインブリーフ

| 項目 | 内容 |
|---|---|
| プレイヤーの約束 | 真っ暗な小学校で、巨大なランドセルザメから逃げつつ、電源を復旧して脱出する。 |
| 狙う感情 | 静かな緊張 → 見つかった瞬間の恐怖 → 逃げ切った安堵。 |
| 主動詞 | **照らす**(懐中電灯で道を探す。ガブガブーノに当てると動きが鈍る) |
| 副動詞 | 歩く、走る(スタミナ制)、拾う、はめる(持っているヒューズをまとめてはめる)、隠れる(棚の陰、非常灯の下) |
| 5〜30秒ごとの繰り返し | 物音を聞く → 照らして確認する → 進むか、隠れるか、走るかを判断する |
| 1〜5分での変化 | ヒューズを1本拾うたびに、ガブガブーノが速く、しつこくなり、聞き取れる範囲も広がる。配電盤のランプが1つずつ灯る。 |
| 失敗と再開 | ガブガブーノに捕まるとジャンプスケア → チェックポイント(ヒューズをはめていれば配電盤の前、まだなら入口)から約3秒で再開。持っているヒューズは失わない。 |
| 報酬とリスク | ヒューズで電源と扉が開く。ライトは電池を消費し、点けていると見つかりやすい。 |
| うまい人の違い | 足音を聞いて消灯でやり過ごし、追われた時だけライトで足止めする。 |
| 次の判断の伝え方 | 足音の大きさと方向、心拍音、画面の縁の暗さ、ガブガブーノの目の色(白=徘徊、黄=警戒、赤=追跡)、追跡中の「ガブガブ」という噛みつき音。 |
| この版でやらないこと | ストーリー演出、複数チャプター、セーブ、パズルの種類増加、スマホ対応。 |

## 2. コアループ契約

> プレイヤーは **懐中電灯で照らしながら探索** し、**3本のヒューズを配電盤にはめて出口を開ける** のが目的。一方、**徘徊し、見つけると追ってくるガブガブーノ** が危険になる。成功すると **照明が戻り、出口へ近づく**。失敗すると **ジャンプスケアの後、チェックポイントから再開** する。

コードで確認する項目:
- [ ] 動詞が実際の入力に対応している(WASD移動、マウス視点、Shift走る、F/右クリックでライト、E拾う・はめる)
- [ ] 目的が画面に見えている(ヒューズ 0/3 のHUD、配電盤のランプ)
- [ ] 最初の1分以内に危険がある(遠くを横切るガブガブーノの影)
- [ ] 報酬が状態を変える(照明の復旧、扉が開く)
- [ ] 失敗の理由が分かる(捕まる直前の目の色変化と足音)
- [ ] 再開が速い(3秒以内)

## 3. レベル計画(チャプター1「搬入口〜組立ライン」)

- **空間**: 一人称。天井の低い廊下と、高い棚が並ぶ倉庫と、ベルトコンベアの組立ホール。棚が視線を遮るので、隠れられる。
- **開始 → 最初の判断 → 最初の脅威 → 最初の報酬**: 昇降口(下駄箱)から入り、薄暗い廊下に出る。廊下の先のロビーで、ヒューズ1本目が光って見える。拾った瞬間、遠くで上履きの足音とチャイムが鳴る。
- **目印**: 多目的ホールの「学校目標」の大看板、長机の列、黒板の落書き、赤い非常灯、分電盤(多目的ホール中央)。
- **難易度の上げ方**:
  - ヒューズ0本: ガブガブーノは遠くの巡回ルートを歩くだけ
  - 1本: 巡回範囲が広がり、物音に反応する
  - 2本: 走る速度が上がり、見失った後も周囲を探す
  - 3本: 配電盤を作動させると全館の照明が点き、出口へのラストチェイスになる
- **回復の場面**: 非常灯の下は安全地帯で、スタミナと電池が回復する。電源を戻した直後は、ガブガブーノが数秒ひるむ。
- **危険の予告**: 足音、天井の照明の明滅、遠くで歪んで鳴るチャイム。追跡に移る前に、ガブガブーノの目が白から赤に変わる。
- **部品化**: 部屋はグリッドの部品(昇降口、図書室、理科準備室、多目的ホール、音楽室、廊下)で組み立てる。ガブガブーノの強さは、速度・視野角・聴覚範囲のパラメータで段階を定義する。

## 4. アート方針
- 「バカバカしいのに怖い」。昼間なら笑える落書きのキャラが、夜の校舎では本気で襲ってくる。
- 校舎: 薄緑の腰壁とクリーム色の壁、木の床、蛍光灯、掲示物、黒板、下駄箱、ロッカー、長机。
- 色: 闇の中の暖色の懐中電灯、ランドセルの赤、非常灯の赤、黒板の緑、上履きの白。
- 霧、ビネット、フィルムグレインで視界を狭める。
- アセットはすべてコードで生成する(外部ファイル0)。2026年のバイブコーディングの流儀(`vibe-research.md`)に合わせる。
  - キャラクター: SDF スカルプト(距離関数をなめらかに合成し、Surface Nets でメッシュ化)
  - 質感と演出: シェーダ(ブルーム、色収差、グレイン、懐中電灯の光の筋とチリ)
- キーが用意できたら、Tripo などの3D生成モデルと見比べる。

## 5. 技術案
- Vite + TypeScript + Three.js(`threejs-gameplay-systems` の雛形)
- PointerLockControls で一人称にする。衝突は壁ボックスとの簡易判定にする(Rapierは不要)。
- 敵AIは「徘徊 → 警戒 → 追跡 → 捜索」の状態機械にする。視線判定は壁ボックスへのレイキャストで行う。
- 音は Web Audio の手続き生成(足音、心拍、ドローン音)。
- 乱数は雛形のシード付きRNGを使う。
- 対象: PCブラウザ(キーボード + マウス)
