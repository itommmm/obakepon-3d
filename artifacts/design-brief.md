# おばけポン 3D — 企画書 v0.3(ホラー版・実装反映)

> 方向性: 「Poppy Playtime のような」一人称ホラー。廃墟のおもちゃ工場、かわいいはずのマスコットが襲ってくる、という雰囲気だけを参考にする。キャラクター・名称・ガジェットはすべてオリジナル。

## 世界観
昭和の終わりに大ヒットした抱き枕おもちゃ「おばけポン」を作っていた **ポンポン玩具工場**。ある夜、工場は従業員ごと消えた。
プレイヤーは30年ぶりに届いた差出人不明の手紙(「まだ ここで まってるよ」)に呼ばれ、閉鎖された工場へ入る。
暗闇の奥には、身長4メートルに育った白いぬいぐるみのマスコット **ポンちゃん** がいる。

## 1. デザインブリーフ

| 項目 | 内容 |
|---|---|
| プレイヤーの約束 | 真っ暗な玩具工場で、巨大なマスコットから逃げつつ、電源を復旧して脱出する。 |
| 狙う感情 | 静かな緊張 → 見つかった瞬間の恐怖 → 逃げ切った安堵。 |
| 主動詞 | **照らす**(懐中電灯で道を探す。ポンちゃんに当てると動きが鈍る) |
| 副動詞 | 歩く、走る(スタミナ制)、拾う、はめる(持っているヒューズをまとめてはめる)、隠れる(棚の陰、非常灯の下) |
| 5〜30秒ごとの繰り返し | 物音を聞く → 照らして確認する → 進むか、隠れるか、走るかを判断する |
| 1〜5分での変化 | ヒューズを1本拾うたびに、ポンちゃんが速く、しつこくなり、聞き取れる範囲も広がる。配電盤のランプが1つずつ灯る。 |
| 失敗と再開 | ポンちゃんに捕まるとジャンプスケア → チェックポイント(ヒューズをはめていれば配電盤の前、まだなら入口)から約3秒で再開。持っているヒューズは失わない。 |
| 報酬とリスク | ヒューズで電源と扉が開く。ライトは電池を消費し、点けていると見つかりやすい。 |
| うまい人の違い | 足音を聞いて消灯でやり過ごし、追われた時だけライトで足止めする。 |
| 次の判断の伝え方 | 足音の大きさと方向、心拍音、画面の縁の暗さ、ポンちゃんの目の色(白=徘徊、赤=追跡)。 |
| この版でやらないこと | ストーリー演出、複数チャプター、セーブ、パズルの種類増加、スマホ対応。 |

## 2. コアループ契約

> プレイヤーは **懐中電灯で照らしながら探索** し、**3本のヒューズを配電盤にはめて出口を開ける** のが目的。一方、**徘徊し、見つけると追ってくるポンちゃん** が危険になる。成功すると **照明が戻り、出口へ近づく**。失敗すると **ジャンプスケアの後、チェックポイントから再開** する。

コードで確認する項目:
- [ ] 動詞が実際の入力に対応している(WASD移動、マウス視点、Shift走る、F/右クリックでライト、E拾う・はめる)
- [ ] 目的が画面に見えている(ヒューズ 0/3 のHUD、配電盤のランプ)
- [ ] 最初の1分以内に危険がある(遠くを横切るポンちゃんの影)
- [ ] 報酬が状態を変える(照明の復旧、扉が開く)
- [ ] 失敗の理由が分かる(捕まる直前の目の色変化と足音)
- [ ] 再開が速い(3秒以内)

## 3. レベル計画(チャプター1「搬入口〜組立ライン」)

- **空間**: 一人称。天井の低い廊下と、高い棚が並ぶ倉庫と、ベルトコンベアの組立ホール。棚が視線を遮るので、隠れられる。
- **開始 → 最初の判断 → 最初の脅威 → 最初の報酬**: 搬入口から入り、薄暗いロビーに出る。分かれ道の先に、ヒューズ1本目が光って見える。拾った瞬間、遠くの扉の向こうでポンちゃんの足音が聞こえる。
- **目印**: 巨大なポンちゃんの看板、止まったコンベア、赤い非常灯、配電盤(中央ホール)。
- **難易度の上げ方**:
  - ヒューズ0本: ポンちゃんは遠くの巡回ルートを歩くだけ
  - 1本: 巡回範囲が広がり、物音に反応する
  - 2本: 走る速度が上がり、見失った後も周囲を探す
  - 3本: 配電盤を作動させると全館の照明が点き、出口へのラストチェイスになる
- **回復の場面**: 非常灯の下は安全地帯で、スタミナと電池が回復する。電源を戻した直後は、ポンちゃんが数秒ひるむ。
- **危険の予告**: 足音、天井の照明の明滅、遠くで鳴るおもちゃの笑い声。追跡に移る前に、ポンちゃんの目が白から赤に変わる。
- **部品化**: 部屋はグリッドの部品(廊下、倉庫、ホール)で組み立てる。ポンちゃんの強さは、速度・視野角・聴覚範囲のパラメータで段階を定義する。

## 4. アート方針
- 「かわいいのに怖い」。ポンちゃんは丸くて白い布おばけで、縫い目の笑顔と、異様に長い腕を持つ。
- 色: 闇の中の暖色の懐中電灯、パステルの玩具色(ピンク、水色)、非常灯の赤。
- 霧、ビネット、フィルムグレインで視界を狭める。
- アセットは手続き的に生成する(外部APIは未使用)。キーが用意できたら、ポンちゃんを3D生成モデルに差し替える。

## 5. 技術案
- Vite + TypeScript + Three.js(`threejs-gameplay-systems` の雛形)
- PointerLockControls で一人称にする。衝突は壁ボックスとの簡易判定にする(Rapierは不要)。
- 敵AIは「徘徊 → 警戒 → 追跡 → 捜索」の状態機械にする。視線判定は壁ボックスへのレイキャストで行う。
- 音は Web Audio の手続き生成(足音、心拍、ドローン音)。
- 乱数は雛形のシード付きRNGを使う。
- 対象: PCブラウザ(キーボード + マウス)
