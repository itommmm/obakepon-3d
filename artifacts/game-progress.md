# 進行メモ

## 現在の意図と制約
- Poppy Playtime 風の一人称ホラー(オリジナルIP)「おばけポン」チャプター1の、最初に遊べる版。
- 対象はPCブラウザ(キーボード + マウス)。スマホ対応は対象外。
- アセットはすべて手続き的に生成する(外部生成APIは未使用)。

## 決定事項
- スタック: Vite + TypeScript + Three.js(`threejs-gameplay-systems` の雛形を `game/` に展開)
- マップ: 26×20グリッド、1マス3m。当たり判定はマス矩形の押し出しで、物理エンジンは使わない。
- 敵AI: 徘徊 / 調査 / 警戒 / 追跡 / 捜索 / 怯みの状態機械。A* と 2D の視線判定。
- 難易度の段階は「拾ったヒューズの本数」で上がる。電源復旧後は「激昂」状態で常に追跡する。
- ヘッドレスでの検証: Playwright 1.60 用のブラウザがないため、`CHROMIUM_EXECUTABLE=/opt/pw-browsers/chromium` で既存の Chromium を使う(インスペクタと playwright.config を対応済み)。

## 完了
- スキル導入(PR #1)
- 企画書 v0.3(`design-brief.md`)
- ゲーム本体: マップ、プレイヤー(懐中電灯、スタミナ、電池)、ポンちゃん(モデル、AI、ジャンプスケア)、ヒューズと配電盤、出口、安全地帯、手続き音響、HUDとメニュー(タイトル、一時停止、捕まった画面、クリア画面)
- 画面検査 pass-4: title / active-play / chase / jumpscare / caught / complete がすべて PASS(予算内)
- 本番ビルド成功

## 残っている課題
- ヘッドレスはソフトウェア描画(約5fps)なので、実GPUでのfpsは未計測。
- 電源復旧後の画面がまだ暗めで、天井灯の効果が弱い。
- 3本目のヒューズはポンちゃんの部屋にあり、難しすぎないかは人による試遊が必要。
