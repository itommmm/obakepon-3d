# 進行メモ

## 現在の意図と制約
- Poppy Playtime 風の一人称ホラー × ブレインロット風キャラ × 夜の小学校。「おばけポン」チャプター1「よふけの ポンポン小学校」の、最初に遊べる版。
- 敵はオリジナルのブレインロット風キャラ「ランドセルザメ・ガブガブーノ」。既存のミームキャラは使わない。
- 対象はPCブラウザ(キーボード + マウス)。スマホ対応は対象外。
- アセットはすべて手続き的に生成する(外部生成APIは未使用)。

## 決定事項
- スタック: Vite + TypeScript + Three.js(`threejs-gameplay-systems` の雛形を `game/` に展開)
- マップ: 26×20グリッド、1マス3m。昇降口、図書室、理科準備室、多目的ホール、音楽室、1階廊下。
- 当たり判定はマス矩形の押し出しで、物理エンジンは使わない。
- 敵AI: 徘徊 / 調査 / 警戒 / 追跡 / 捜索 / 怯みの状態機械。A* と 2D の視線判定。
- 見た目は `GabugabunoModel.ts` に分離。かぶせ(アゴ)の開閉、細長い足の歩行、ひれ。
- 難易度の段階は「拾ったヒューズの本数」で上がる。電源復旧後は激昂状態で常に追跡する。
- ヘッドレスでの検証: `CHROMIUM_EXECUTABLE=/opt/pw-browsers/chromium` で既存の Chromium を使う。

## 残っている課題
- ヘッドレスはソフトウェア描画(約5fps)なので、実GPUでのfpsは未計測。
- 3本目のヒューズは音楽室(ガブガブーノの初期位置)にあり、難しすぎないかは人による試遊が必要。
