# おばけポン 3D

閉鎖されたおもちゃ工場を舞台にした、ブラウザで遊ぶ一人称ホラーゲームです。巨大なぬいぐるみマスコット「ポンちゃん」から逃げながら、ヒューズを3本集めて電源を戻し、工場から脱出します。

Poppy Playtime のような「かわいいのに怖い」雰囲気を目指しています。キャラクター、名称、仕掛けはすべてオリジナルです。

![追いかけてくるポンちゃん](docs/screenshots/chase.png)

## 遊び方

```bash
cd game
npm install
npm run dev
# → http://127.0.0.1:5188 をブラウザで開く
```

| 操作 | キー |
|---|---|
| 移動 | `W` `A` `S` `D` |
| 見回す | マウス(画面クリックでマウスを固定)/ `←` `→` |
| 走る | `Shift`(スタミナを消費) |
| 懐中電灯 | `F` / 右クリック |
| 拾う・はめる | `E` |
| 一時停止 | `Esc` |

ヘッドホン推奨です。大きな音とびっくりする演出があります。

## 機能(チャプター1)

- **目的**: 工場内に散らばったヒューズを3本集め、中央ホールの配電盤にはめる。電源が戻ると出口の扉が開く。
- **ポンちゃんのAI**: 徘徊 → 警戒 → 追跡 → 捜索の状態機械で動く。視界は扇形で、壁や棚で遮られる。足音も聞き取る。経路探索はA*。
  - 目の色で状態がわかる(白 = 徘徊、黄 = 警戒、赤 = 追跡)。
  - ヒューズを拾うほど速く、しつこくなる。電源復旧後は常にプレイヤーを追う。
- **懐中電灯**: 点けると周りが見えるが、遠くから見つかりやすい。ポンちゃんに当てると動きが鈍るが、電池を早く消費する。
- **非常灯の下(安全地帯)**: ポンちゃんに見つからず、電池とスタミナが回復する。
- **ジャンプスケアと再開**: 捕まると顔が迫る演出のあと、チェックポイント(入口、または配電盤の前)から再開する。
- **音**: Web Audio だけで手続き的に生成する。HRTFで方向がわかる足音、近づくと速くなる心拍、低いドローン音、遠くのおもちゃの笑い声、叫び声など。
- **ビジュアル**: アセットはすべて手続き的に生成する(壁紙、ポスター、棚のおもちゃ、ぬいぐるみ、ポンちゃん本体)。外部の画像や3Dモデルは使わない。

## 技術仕様

| 項目 | 内容 |
|---|---|
| 構成 | Vite 8 + TypeScript + Three.js r184 |
| マップ | 26×20マスのグリッド(1マス3m)。`game/src/world/levelData.ts` の文字列で定義 |
| 当たり判定 | マスごとの矩形と円の押し出し(物理エンジンなし) |
| 敵AI | `game/src/entities/Monster.ts`(状態機械 + A* + 視線判定) |
| ライティング | 懐中電灯のスポットライト(影あり)、非常灯、電源復旧で点く天井灯、指数フォグ |
| 乱数 | シード付きRNG(`utils/random.ts`)。テストを再現可能にするため、ゲームプレイの乱数はすべてここを通す |
| テスト用フック | `window.__THREE_GAME_TEST_HOOKS__`(状態: `title` / `active-play` / `chase` / `jumpscare` / `caught` / `finale` / `complete`)と `window.__THREE_GAME_DIAGNOSTICS__` |

### ディレクトリ

```
game/
  src/core/      ループ、レンダラー、入力
  src/world/     マップ定義、レベル生成、手続きテクスチャ
  src/entities/  プレイヤー、ポンちゃん、ヒューズ
  src/systems/   音、HUD、デバッグ用パネル
  src/game/      ゲーム進行(Game.ts)
  tests/         Playwright(画面確認、ボットによるプレイテスト)
artifacts/       企画書と進行メモ
.claude/skills/  ゲーム制作用の Claude Code スキル(threejs-game-skills)
```

### 開発用コマンド

```bash
npm run build          # 型チェックと本番ビルド
npm run inspect:canvas # 各状態の画面をキャプチャして検査
npx playwright test tests/bot-playtest.spec.ts --project=desktop-chrome  # ボットのプレイテスト
```

`?debug` を付けて開くと、移動速度、マウス感度、懐中電灯の明るさを調整するパネルが出ます。
