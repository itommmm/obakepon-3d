# おばけ第一小学校 夜の学校おばけポン！

夜の小学校で、置き忘れのおもちゃが「怖かわいい」おばけに変身。タップで撃って退治する3Dシューティングです（three.js製）。流血表現はありません。将来のRoblox移植を前提にしています。

## 遊び方

- ブラウザで `index.html` を開く（または `dist/obakepon.html` 単体）
- 開始画面で難易度（やさしい／ふつう／むずかしい）を選んで「はじめる」
- おばけをタップ（PCはクリック）で撃つ。放っておくと飛びかかってきてハートが減る

| ステージ | 場面 | 内容 |
|---|---|---|
| 1 | 夜の教室 | 一人称シューティング。WAVE1〜5、最後にボス |
| 2 | あかね色の教室 | 敵が強化。WAVE2〜4はランダムイベント（停電・大行進・ぬいぐま行進・ゴールドラッシュ） |
| 3（最終） | おもちゃ宇宙 | 奥へ飛ぶスクロール。指（マウス）で「ひよっこ号」を動かし、塔と敵の弾をよける。自動連射。50秒後に最終ボス |

| 操作 | 内容 |
|---|---|
| タップ／クリック | 撃つ（最終ステージは移動） |
| Z ライト | おばけを数秒止める（最終ステージはスロー） |
| X チャイム | 弾とハートを回復 |
| C スペシャル | ゲージ満タンで全員に大ダメージ |

- WAVEの合間に、パワーアップを3択から1つ選ぶ
- 金のウサギを撃つとフィーバー（得点2倍）。ヒヨコは味方なので撃たない
- 連続ヒットでコンボ倍率（最大×3）。HUDに倍率を表示

## 今回の大改修（v2.0）

| 区分 | 内容 |
|---|---|
| 遊び | 難易度選択（ハート数・敵の速さ・得点倍率）。最終ステージで敵とボスが弾を撃つ（よける要素） |
| 手ごたえ | 被弾・ボス撃破で画面が揺れる（「視差効果を減らす」設定時は無効）。コンボ倍率を表示 |
| 不具合修正 | 最終ボスが手下を呼ばない問題、10分以上の時間表示、ステージ切替直後の敵の残留、自機が小さく見えにくい問題 |
| 品質 | 長時間プレイでのメモリ増加を防止（ジオメトリ共有と解放）。重い端末では解像度を自動で下げる |
| 構成 | リポジトリ化（ソース・ライブラリ・配布物を分離）、ビルドと自動テストを追加 |

## ファイル構成

```
obakepon-3d/
├── index.html            # 開発用ページ（vendor と src を読み込む）
├── src/main.js           # ゲーム本体
├── vendor/three.min.js   # three.js r128（MIT。LICENSE-three.txt）
├── pwa/                  # ホーム画面追加用（manifest・Service Worker・アイコン）
├── tools/build.py        # 配布物を作る
├── tools/smoke.mjs       # 全ステージを自動で進める動作テスト
├── dist/obakepon.html    # 単体HTML（これ1つで動く）
├── dist/web/             # サーバーに置くホーム画面版一式
└── docs/ROBLOX_PORT.md   # Roblox移植メモ
```

## 開発（Mac）

1. ゲームを直す：`src/main.js` を編集し、`index.html` をブラウザで開いて確認
2. 配布物を作る：ターミナルで `python3 tools/build.py`
3. 自動テスト（任意）：`npm i playwright && npx playwright install chromium` のあと `node tools/smoke.mjs "$PWD/dist/obakepon.html"`
   - 環境に合わせて `CHROME_PATH` でブラウザを指定できます

## iPhoneで遊ぶ

| 方法 | 全画面 | 手順 |
|---|---|---|
| Webサーバーに置く（推奨） | ○ | `dist/web/` の中身をHTTPSのフォルダへアップロード → Safariで開く → 共有 →「ホーム画面に追加」 |
| GitHub Pages | ○ | リポジトリを Public にして Pages を有効化（Private のままでは無料プランで公開不可） |
| HTML単体 | × | `dist/obakepon.html` を AirDrop → HTMLを表示できるアプリで開く |

- 縦持ちでは「横向きにしてね」を表示して停止します
- マナーモードがオンだと音は出ません
- 更新を端末に届けるときは、`pwa/sw.js` の `CACHE` の番号を上げてからビルドします
